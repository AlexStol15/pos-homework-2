# ПОС — Преподавательская Оценка Студентов

POS - это консольное приложение для выставления оценок учащимся по одному курсу с общей взвешенной рубрикой. Преподаватели могут управлять учащимися и критериями, назначать, исправлять и удалять оценки, просматривать результаты и экспортировать их в CSV.

Application → Domain
Infrastructure → Application, Domain
Console → Application, Domain, Infrastructure

## Build and run

Из корневого хранилища с установленным .NET 10 SDK запустите:

```sh
dotnet restore PosHomework.slnx
dotnet build PosHomework.slnx --no-restore
dotnet run --project Console --no-build
dotnet test PosHomework.slnx --no-build
```

Выберите пункт меню с нумерацией и следуйте инструкциям. Идентификаторы учащегося и критерия генерируются автоматически. В списке параметров отображаются их идентификаторы. Выберите **Calculate student result**, чтобы отобразить оба балла.

## Domain and architecture

`Student` и `Rubric` являются совокупными корнями. Учащийся владеет своими оценками и позволяет выставлять одну текущую оценку по каждому критерию. Рубрика владеет своими критериями и управляет их жизненным циклом. После присвоения действительной оценки критерий блокируется навсегда. Заблокированный критерий нельзя отредактировать или удалить даже после удаления всех его оценок.

`Student` и `Criterion` являются сущностями. При переименовании студент сохраняет тот же идентификатор. `Оценка` - это объект с неизменяемым значением. Например, два подтвержденных балла со значением 8 равны по значению, при этом в каждой оценке указывается, по какому критерию был получен балл.

Приложение использует шестиугольную архитектуру. `Domain` не зависит от проекта. `Application` зависит от `Domain` и определяет порты хранилища и экспорта. `Infrastructure` зависит от обоих и реализует эти порты с помощью JSON и CSV. `Console` регистрирует реализации в Microsoft.Extensions.DependencyInjection и вызывает фасад.

- **Factory** in `Domain`. `EvaluationFactory` просматривает каждый критерий и создает оценку с баллами в допустимом диапазоне от нуля до максимума.

- **Facade** in `Application`. `PosFacade` предоставляет меню единую точку входа. В нем координируются ученик и рубрика, поэтому присвоение оценки и фиксация критерия сохраняются вместе.

- **Strategy** in `Domain`. `ScoreCalculator` делегирует функции `StrictFinalStrategy` or `ProvisionalStrategy`. В меню отображаются оба результата, а при экспорте в формате CSV используется конечный результат, если он доступен.

## Results and files

Результат равен `10 × Σ(weight × score / maxScore) / Σ(weight)`. Веса являются положительными и относительными, поэтому их можно суммировать с любым положительным числом. Для получения окончательного результата требуется оценка по каждому критерию. В предварительном результате используются только оцененные критерии и их веса. Оба результата недоступны, если нет оценок или критериев. Приложение вычисляет баллы на основе текущих данных и форматирует результаты с точностью до двух знаков после запятой для отображения и экспорта.

Приложение считывает и записывает файл `data.json` в свой рабочий каталог. При отсутствии файла начинается создание пустой рубрики и списка учащихся. Если существующий файл недействителен, приложение сообщает об ошибке и сохраняет файл. Перед заменой сохраненного состояния записывается временный файл, и блокировка файла предотвращает перезапись изменений при одновременном сохранении.

При экспорте файл `results.csv` записывается в один и тот же каталог с одной строкой на каждого учащегося. Он включает идентификатор, имя, статус и оценку учащегося. Статус - `Final`, `Provisional`, или `NotGraded`. В графе `NotGraded` не указано иное.
